# Приложение для изучения слов 


## 📋 Возможности

- **Выбор файла**: Графический интерфейс для выбора текстовых файлов
- **Синтез речи**: Произношение слов с помощью Windows Speech API
- **Случайный порядок слов**: Слова представляются в случайной последовательности без повторений
- **Отслеживание прогресса**: Показывает количество оставшихся слов и затраченное время
- **Отслеживание ошибок**: Собирает и отображает неправильно отвеченные слова
- **Функция пропуска**: Введите "след" чтобы пропустить слово
- **Поддержка форматов**: Поддерживает .txt и другие текстовые файлы в кодировке UTF-8
## 🚀 Начало работы

### Требования

- .NET Framework 4.7.2 или новее / .NET 6.0+
- Windows OS (требуется для System.Speech)
- Visual Studio 2019+ или Visual Studio Code с расширением C#

### Установка

#### Способ 1: Через консоль диспетчера пакетов Visual Studio

```powershell
Install-Package System.Speech
Install-Package System.Windows.Forms
```

#### Способ 2: Через .NET CLI

```bash
dotnet add package System.Speech
dotnet add package System.Windows.Forms
```

#### Способ 3: Через PackageReference (добавить в .csproj)

```xml
<PackageReference Include="System.Speech" Version="8.0.0" />
<PackageReference Include="System.Windows.Forms" Version="1.0.2" />
```

### Сборка проекта

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/word-learning-app-csharp.git
cd word-learning-app-csharp

# Восстановите пакеты
dotnet restore

# Соберите проект
dotnet build

# Запустите приложение
dotnet run
```

## 📖 Использование

1. **Запустите приложение**
2. **Выберите текстовый файл** при появлении диалога выбора файла
3. **Слушайте** произносимое слово
4. **Введите слово**, которое услышали, и нажмите Enter
5. **Используйте "след"** для пропуска слова при необходимости
6. **Просмотрите ошибки** в конце сессии

### Формат входного файла

Приложение принимает текстовые файлы с:
- Словами, разделенными пробелами, табуляцией или переводами строк
- Кодировкой UTF-8
- Любым распространенным текстовым форматом (.txt и др.)

Пример входного файла:
```
яблоко банан вишня
собака кот мышь
программирование язык
```

## 🛠️ Технические детали

### Ключевые компоненты

- **Обработка файлов**: Читает и парсит текстовые файлы с правильной кодировкой
- **Очистка слов**: Удаляет специальные символы: `!"#$%&()*+,-./:;<]^_`|~`
- **Синтез речи**: Использует Windows SAPI для преобразования текста в речь
- **Случайный выбор**: Гарантирует отсутствие повторов слов во время сессии
- **Обработка ошибок**: Всесторонняя обработка исключений для файловых операций

### Архитектура

```
WordLearningApp/
├── Program.cs              # Основная логика приложения
├── LoadWordsFromFile()     # Выбор и парсинг файла
├── DeleteBadSignsFromWords() # Очистка текста
├── RunLearningSession()    # Основной цикл обучения
└── README.md              # Этот файл
```

## 🔧 Решение проблем

### Частые проблемы

1. **Речь не работает**: Убедитесь, что Windows Speech API доступен и настроен
2. **Проблемы с кодировкой файла**: Убедитесь, что текстовые файлы сохранены в кодировке UTF-8
3. **Установка пакетов**: Выполните `dotnet restore` после клонирования

### Системные требования

- **Windows 10/11** (для System.Speech)
- **.NET Framework 4.7.2+** или **.NET 6.0+**
- **Устройство вывода звука** для синтеза речи
